# PixelPet 🐾

A tiny pixel pet that lives on your Mac desktop.

## Current MVP

- Transparent floating pet window
- Always-on-top desktop companion
- Draggable pet
- macOS-friendly Electron shell
- System tray
- Basic pet interaction
- Double-click chat prototype
- Pixel-art cat built with CSS

## Run locally

```bash
npm install
npm start
```

## Build a macOS app

```bash
npm run build
```

The DMG will be generated under `dist/`.
